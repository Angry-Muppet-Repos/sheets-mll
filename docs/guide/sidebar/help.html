Five steps to a working sheet

Ten minutes from blank to a moving Dashboard. Stop reading after this section and you have everything you need.

1 Make your copy

Open the_foundation_v2_BLANK.xlsx in Drive. Right-click → Open with → Google Sheets, then File → Save as Google Sheets. The file lives in your Drive — Column & Co. never sees it.

2 Install the script

  1. Extensions → Apps Script. A new tab opens.
  2. Delete the placeholder Code.gs content.
  3. For each .gs file in your download, File → New → Script, name it to match, paste the contents. Save.
  4. For the sidebar: File → New → HTML, name it Help, paste in Help.html.
  5. Reload the sheet. The 💳 Column & Co. menu appears.
  6. Run 💳 → Setup → Build workbook (mock data or blank) to lay out all 14 tabs.

First menu click prompts for permission. The script asks for spreadsheets.currentonly — the narrowest scope Google offers. Approve.

3 Add your accounts

Go to Accounts. One row per checking account, credit card, savings account. Name, Type, Owner, current balance. The Last Updated column stamps itself — don't touch it.

Investments (401(k), brokerage, IRA) go on Net Worth, not Accounts.

4 Pick your profile

On Monthly Budget, run 💳 → Apply Budget Profile. Ten profiles — Dave Ramsey through Kakeibo through HCOL Renter through Custom.

Preset % (Cream, locked) is the canonical numbers. Override % (yellow, column D) is where your tweaks go — leave blank to use the preset, or type a percent to override. Each profile keeps its own overrides.

5 Import your first month

  1. Export 30 days of CSV from your bank.
  2. On Bank Import Guide, pick your account from the C10 dropdown.
  3. Paste the CSV anywhere in the green zone.
  4. 💳 → Import Bank Transactions.
  5. Cursor jumps to Review Income (confirm Yes/No) or Uncategorized Merchants (pick a category to save a permanent rule).

Chase, BoA, Wells, Cap One, Ally, Citi, USAA, Discover, Amex headers all recognized. Re-importing is safe — duplicates are skipped.

6 Pick your look

💳 → Apply Theme — 24 palettes. Pick one, sheet repaints. The brand chrome stays locked; only the interior changes.

You're operational. Open Dashboard — KPIs, donut, AI Insights all reading your data. Open Health Score for the one-number read. Open Trends for the six-month sparklines.

Menu reference

Every item in the 💳 Column & Co. menu. Listed in display order.

Add Account…

Prompts for an account name, appends a new row to Accounts with sensible defaults (Checking, Joint, today's date), and parks your cursor on Starting Balance. Duplicate names are rejected case-insensitively.

Import Bank Transactions

Reads the paste zone, sniffs the header against nine bank formats, dedupes against the ledger, auto-categorizes, and appends to Transactions. Cursor jumps to Review Income (rows 65-84) or Uncategorized Merchants (rows 89-108) — whichever needs you.

Clear Paste Zone

Empties the 50×8 paste-zone grid. Confirmation dialog first. Review and Uncategorized queues are untouched.

Recategorize Ledger from Rules

Walks every Misc row in Transactions and reapplies your keyword rules (longest match wins). Rows you've manually categorized are never overwritten.

Sort Transactions by Date

Sorts the ledger newest-first. Imports already trigger this — use the menu item after manually adding rows.

Apply Theme ▸

Submenu of all 24 palettes. Active palette has a ✓. Repaints every content cell on every tab; the brand chrome stays locked. Choice persists across reloads.

Apply Budget Profile ▸

Submenu of the 10 profiles plus Clear overrides for current profile…. Active profile has a ✓. Each profile keeps its own overrides — switching never loses your tweaks.

Renumber Ledger

Re-applies data validation dropdowns and number formats to all 5,000 rows of Transactions. Idempotent — safe to run anytime.

Help…

Opens this sidebar.

Setup ▸

Destructive. Rebuilds the entire workbook from scratch — every tab, named range, and Document Property is reset. Two options: Build workbook (mock data) seeds with Marcus & Elena Brooks; Build workbook (blank) seeds with no data. Use once on a fresh install or to start over.

Stuck?

The 💳 Column & Co. menu didn't appear

The script isn't installed yet. Quickstart · Step 2. After pasting and saving, reload the sheet — the menu loads on open, not on save.

Google is asking for permission

Expected on first menu click. The scope is spreadsheets.currentonly — the narrowest one Google offers. Approve.

Import said "no rows imported"

The paste zone might be empty, or the header row didn't match a known bank format. Confirm the first line of your paste is a header (e.g. Date,Description,Amount) and that the account name in C6 matches an entry on the Accounts tab.

Half my transactions are Misc

The keyword rules don't yet cover those merchants. Add rows on the Categories tab, then run Recategorize Ledger from Rules.

The palette didn't paint

Some cells you've manually filled override the script. Pick the palette again, or reset the manual fill via Format → Conditional formatting → Clear.

My Custom budget disappeared

Switching profiles overwrites the targets. The script snapshots Custom values before any switch — switch back to Custom and they return. If they don't, the snapshot wasn't saved (run Save Current Values as Custom next time before switching).

The sheet feels slow

Past about 3,000 transactions, recalc gets sluggish. Run Renumber Ledger and consider archiving older months to a copy.
